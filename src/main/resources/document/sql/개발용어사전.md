# 개발용어사전
## DDD(도메인 주도 디자인 - Domain Driven Design) 를 활용한 개발 

## DDD의 핵심 구성요소
- 엔티티`(Entity)`
- 값 객체`(Value Object)` 
- 서비스`(Service)` 
- 리포지토리`(Repository)` 
- 집합`(Aggregate)`

### Aggregate(애그리거트)
- 정의
  - 애그리거트는 연관된 객체들을 하나의 군집으로 묶은 도메인 모델의 단위입니다.
    이 군집의 **루트 엔티티(Aggregate Root)**를 통해서만 외부에서 접근하거나 변경할 수 있도록 제한합니다.
- 구성요소
  - Aggregate Root (애그리거트 루트)
    1. 애그리거트를 대표하는 중심 엔티티
    2. 외부에서 루트를 통해서만 내부 구성요소에 접근 가능
  - 내부 구성요소(Entity 또는 Value Object)
    1. 루트 엔티티와 밀접하게 연관되어 함께 관리됨
    2. 외부에서 직접 접근하거나 수정 불가
- 예시
  > 애그리거트: 주문(order)
  > > 루트 엔티티: order
  > > > 내부 구성요소: OrderLine (주문 항목), DeliveryInfo (배송 정보)
- 왜 중요한가?
  - 일관성 유지: 변경은 루트를 통해서만 일어나므로 무결성을 보장
  - 트랜잭션 경계: 보통 하나의 애그리거트는 하나의 트랜잭션에서 처리
  - 모델의 응집도 향상: 관련된 도메인 개념을 하나의 단위로 묶음
